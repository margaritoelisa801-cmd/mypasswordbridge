# MyPasswordBridge starter (Android/Kotlin)

Starter project for an encrypted local credential vault and a deliberately disabled USB HID boundary.

Project website: [mypasswordbridge.infinityfree.io](https://mypasswordbridge.infinityfree.io/?i=1)

## Requirements
- Android Studio with JDK 17
- Android SDK 35
- A device/emulator running Android 8.0+ for the vault prototype

## Build
Open this folder in Android Studio and sync Gradle. From a terminal with Android SDK configured:
```bash
./gradlew assembleDebug
```
A Gradle wrapper is not included in this starter; Android Studio can generate one, or use the wrapper from a new Android Studio project.

## Important HID limitation
The `UnsupportedHidController` is intentional. Public Android app APIs do not generally let an ordinary non-root app change the phone's USB device identity into a keyboard. Do not replace this with arbitrary root shell commands. First identify the exact phone model and verify its kernel/USB gadget support. Keep real password sending disabled until that capability and the Italian keyboard mapping are tested.

## Security status
This is a development starter, not a production password manager:
- Room stores password and username ciphertext; titles remain visible.
- AES-GCM uses a key generated by Android Keystore.
- BiometricPrompt / per-use authentication is not yet wired into decryption.
- UI does not yet implement import/export, clipboard handling, backup/restore, or a full threat model.
- No real HID transmission is implemented.
- Password zeroing is best-effort on the JVM and cannot guarantee all internal copies are erased.

Before storing real credentials, add authentication-bound key use, lock timeout, screen-capture protection where appropriate, security tests, database migration tests, and an audited HID transport.
